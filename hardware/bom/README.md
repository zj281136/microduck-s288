# 物料与采购数据

[BOM.csv](BOM.csv)是机器可读主表，[BOM.xlsx](BOM.xlsx)是带小计/总计公式的填写表。兼容路径`hardware/bom.csv`保留相同数据；更新时两份CSV需同步。

未知价格、链接、电气规格与线长留空。空白不等于0；XLSX只有数量/价格完整、币种一致且日期完整时才显示全表金额。公式由Excel/LibreOffice打开时重算，本阶段只检查OOXML结构，未验证具体表格软件显示。

`required=alternative`表示供电路径等备选项，不应将电池和台架电源机械相加当作最低整机成本。选定方案、补齐紧固件型号后才能给出有效报价。价格字段必须包含币种与采集日期；采购链接可能失效。

接口/线长、压接或焊接要求尚未完成实物核对，因此“免焊接/无需定制PCB”是设计目标，未形成全BOM验收结论。
