# 一块一块，把鸭子装起来

先把零件按左右腿、躯干和头部分好，桌面会清楚很多。接下来从脚掌和小腿开始，一组一组装，边装边确认编号、活动空间和线束位置。

具体螺钉规格、舵盘角度和局部尺寸还要对照匹配的S288装配图。图还没补到的地方会留`TODO`，先别靠拧紧或软件零位把机械问题藏起来。

## 1. 零件清点与打印检查

**所需零件：**原鸭头S288打印件、S288电机、舵盘/连接件、轴承、螺钉和嵌件。具体型号和数量见[BOM](../BOM.md)，完整打印件版本`TODO`。

**工具：**与实际螺钉匹配的工具、尺寸测量工具；具体规格`TODO`。

**步骤：**

1. 将左右腿、躯干、颈部和头部零件分组。
2. 按文件版本检查左右件、孔位、承力层和安装面。
3. 局部试装电机、轴承和舵盘，不先强行锁紧整机。
4. 记录零件质量，以及是否包含螺钉、轴承和线缆。

**方向与预期状态：**左右件可明确区分；关键配合无需强行挤压，安装面可贴合。

**常见错误：**使用XL330专用连接件配S288、把仿真网格直接当打印文件、切片缩放单位错误。

## 2. 电机编号与机械位置

装配前按[电机ID表](04-motor-calibration.md)贴标签。整机共15个舵机：左腿5个、右腿5个、颈部/头部4个参与RL，另1个不进入当前RL策略。

| 分组 | 从身体到末端的关节命名 |
| --- | --- |
| 左腿 | left_hip_yaw → left_hip_roll → left_hip_pitch → left_knee → left_ankle |
| 右腿 | right_hip_yaw → right_hip_roll → right_hip_pitch → right_knee → right_ankle |
| 颈/头 | neck_pitch、head_pitch、head_yaw、head_roll，安装关系以模型树为准 |

## 3. 脚掌、脚踝和小腿

**所需零件：**脚掌、脚踝连接件、小腿件、膝部连接件、相应电机及支撑轴承；规格`TODO`。

**步骤：**

1. 试装脚掌与脚踝连接，确认舵盘/输出轴安装面。
2. 连接小腿和膝部组件，检查输出侧与支撑侧是否按设计同轴。
3. 未通电条件下按可动结构检查干涉和线束活动空间，不暴力反向驱动机构。
4. 完成一侧检查后再装另一侧，逐项核对镜像件。

**安装方向：**舵盘朝向、零位角与螺钉长度`TODO`，需要明确图示后才能完成这部分精确装配。

**预期状态：**无明显松动；螺钉不顶底或突出到运动空间；线束不被关节夹住。

**常见错误：**左右件混装、轴承受侧向挤压、螺钉过长、脚踝行程中线缆被拉紧。

## 4. 髋部、躯干和电池

**所需零件：**髋部yaw/roll/pitch连接件、躯干壳体、电池固定件和对应紧固件。

**步骤：**

1. 根据模型和已确认的装配图，逐级连接髋pitch、roll、yaw组件。
2. 将左右腿连接到躯干，确认电机编号与左右位置。
3. 预留电池、板卡和线束的固定位置，不让线束穿过夹紧面。
4. 按对应V0位置固定电池，避免动作时滑动。

V0电池模型质量155g，尺寸记录24×31×73mm，相对原电池模型后移2mm、下移1mm。该相对偏移不是任意打印件上可直接测量的孔位尺寸，最终安装图`TODO`。

**预期状态：**左右连接对称关系明确，电池可靠固定，线束在髋部运动时不受拉扯。

**常见错误：**用偏斜安装抵消左右零位差、在软件里补偿滑动电池、把不同模型的电池位置直接沿用。

## 5. 颈部、原鸭头与主控

**所需零件：**颈部和原鸭头结构、电机及motor_support、Pi固定件、IMU固定件。

**步骤：**

1. 按模型树确认neck_pitch、head_pitch、head_yaw、head_roll的轴序和安装面。
2. 每完成一层连接就检查运动空间，不等到锁紧头壳后再排查。
3. 固定Pi与IMU，记录实际安装位置和方向。
4. 安装原鸭头外壳，检查线束出口及头部运动余量。

整机按15个舵机装配，第15个按装配图安装，不进入当前14关节RL策略。头部Pi模型记账18g；摄像头、镜头和镜头座不作为必需物料。

**预期状态：**头部与颈部无结构干涉，主控和IMU不会相对机体晃动，线束不限制头部行程。

**常见错误：**颈部轴序混淆、IMU朝向未记录、头壳夹线、更换头部后只改总重量不改重心惯量。

## 6. 模型零位与站立HOME

机械装配完成后，必须能够明确复现模型`q=0`姿态。它用于捕获电机标定零位，不是机器人自然站姿，也不是电机上电的零点。

站立`HOME`是策略的默认姿态，带有设计好的腿部和颈部角度。观测使用`q−HOME`，动作目标从HOME叠加。将站立HOME当作标定零位会使整条控制链偏移。

## 7. 通电前机械验收

| 检查项 | 预期状态 |
| --- | --- |
| 编号与左右件 | 与ID、joint和实物位置一致 |
| 紧固件 | 型号/长度明确，无松动、顶底和干涉 |
| 轴与支撑 | 安装符合图纸，轴承无明显挤压 |
| 线束 | 无夹压，运动范围内有余量 |
| 板卡与电池 | 固定可靠，不随动作移动 |
| IMU | 安装方向可辨认且固定可靠 |
| 标定参考 | q=0有明确图示和实际对应 |

机械验收不能代替电气极性、接口电平和保护核对。下一步进入[电气连接](03-electronics.md)。
