# XL330迁移到S288

迁移保留policy/action框架，替换执行器和硬件接口；不是把电机名称改掉即可。需核对SDK增益单位、gear ratio、转子/输出编码器、firmware PD、限幅、friction与command lag。

本配置采用XL330-style被动机构与S288-native rotor反馈，是有意差异而非原始编码器语义逐行复刻。对比与来源见设计决策和parameter_sources。

low-pass必须按具体源码版本确认；当前训练/部署均不额外滤目标。上游其他版本的滤波参数不自动移植到本checkpoint。
