# 工程经验与证据等级

| 现象 | 早期假设 | 可支持的结论 | 仍需验证 |
| --- | --- | --- | --- |
| q快速变化但协议qdot很小 | 单纯带宽不足 | q与qdot可能来自不同机械侧，应先核对字段 | 负载下转子/输出映射 |
| 通讯错误伴随动作增强 | 全由PD导致 | 电源、长线、接头和总线必须独立排查 | 同条件线束/供电对照 |
| 转子与OutPos差值有数度摆幅 | 全部都是backlash | 固定偏置/角度映射/柔顺也影响差值，不能以总摆幅认定齿隙 | 每电机回程与负载辨识 |
| play稳定但实机不同 | policy一定有问题 | normalizer、观测、command、随机推力和物理条件需对齐 | 同ONNX闭环对照 |
| 换头后更差 | 只改质量就足够 | 重心、惯量和安装力臂同样重要 | 对应头部动力学 |

所有实验发布应按“背景→假设→条件/方法→数据→观察→结论→复现→局限”组织。没有数据时保留观察/TODO，不编造曲线或提升百分比。
