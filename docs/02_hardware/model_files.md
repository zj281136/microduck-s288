# 图纸、打印件和仿真模型，分别从哪里找？

准备制作时，最想找到的通常是一套能打开、能打印、能装起来的文件。这里先把几种格式对应起来，免得拿到仿真网格后，以为已经备齐了制作图纸。

## 1. 四种模型文件的区别

| 文件类型 | 主要用途 | 使用阶段 |
| --- | --- | --- |
| SolidWorks `SLDPRT/SLDASM` | 修改零件、检查配合、查看完整装配 | 机械设计与适配 |
| STEP `STEP/STP` | 跨软件传递实体几何，检查尺寸与装配 | 模型查看、二次设计 |
| STL | 三角网格；打印或仿真可视化 | 切片打印、模型显示 |
| MJCF `XML` | 定义刚体、关节、质量惯量、限位、传感器和执行器 | MuJoCo 仿真与训练 |

STL 不保留完整参数化设计，通常也不能据文件本身可靠确认单位。MJCF 则不是可打印设计图。

路径相对仓库根目录。最终训练模型不仅是基础 XML：模型工厂还应用 V0 质量设置并加入被动 hinge，task 再设置增益及 DR。

工作区其他机械臂的 STEP、不同头部的 STL 不属于本公开版本，不应因文件格式相同就混用。

## 3. SolidWorks / STEP 检查

打开 SolidWorks 装配时，先检查外部引用是否完整、零件是否缺失及装配配合是否失效。只有主装配文件而缺少零件引用，不能认为获得了完整可编辑工程。

STEP 导入后检查已知电机尺寸、安装孔距和左右方向。若只得到散件而没有共同装配坐标，需要重新确认装配变换，不能分别居中后直接当成正确装配。

## 4. STL 检查

1. 核对单位和整体尺寸。
2. 确认版本、左右件和数量。
3. 检查电机、轴承、螺丝和舵盘的配合位置。
4. 将“用于仿真”和“经过打印验证”分别标注。
5. 按对应材料和打印方向设置切片，不能从仿真网格推断强度。

## 5. 修改模型后的同步项

修改头部、支架或电池后，应核对安装位置、质量、重心、惯量、碰撞几何和限位。显式指定惯量的模型不会仅因替换外观 STL 就自动更新动力学。

配套策略只针对已记录配置。模型变化后需重新评估训练和真机适配，不能以模型“看起来正确”代替动力学核对。

模型来源和分发许可应逐项记录，详见[资源索引](../../hardware/RESOURCE_INDEX.md)。
