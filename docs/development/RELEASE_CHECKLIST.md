## 安全与信息

- [ ] 搜索密钥、密码、邮箱/个人信息、私有IP、机器路径、序列号及敏感日志字段；自动扫描不等于完整人工审查。
- [ ] 不提交本机标定、.env、.venv、日志、缓存、大PT或厂商工具/固件。
- [ ] 硬件命令标注是否零增益请求/运动，保留显式arm，不提供默认开机运动。
