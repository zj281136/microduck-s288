# 为什么使用 S288

## 1. 目标与约束

整机需要15个舵机，其中14个关节参与RL，并与现有Pi实时部署、关节标定和强化学习训练链路配套。选择电机不仅比较标称扭矩，还涉及机械安装、总线、反馈来源、内部控制环和可建模性。

## 2. 方案比较

| 方面 | XL330原版路线 | S288路线 |
| --- | --- | --- |
| 软件基础 | 上游Microduck对应驱动与执行器 | 现有S288串口驱动及M1适配 |
| 机械连接 | 原版舵盘和支架 | S288匹配连接件与安装面 |
| 协议 | 原版电机协议 | 当前6Mbps协议实现 |
| 反馈 | 按对应版本源码核对编码器语义 | rotor位置/速度与OutPos均可记录 |
| firmware与模型 | 对应XL330实现 | S288 firmware PD + M1 BAM |

## 3. 当前选择及取舍

使用S288可以延续现有电机、通信和标定工具，但需要独立的硬件参数与控制模型，不能把XL330具体电机数值直接复制过来。

现有反馈实验使rotor-only成为公开配方：policy的q/qdot与内部PD来自同一侧。OutPos继续留在日志中用于检查输出侧差异，而不是为了减少维度就丢掉诊断数据。

## 4. 需要保留的适配

- 正确的齿比、协议缩放和方向映射。
- 对应SDK Kp/Kd，而不是未经换算的物理PD参数。
- M1的摩擦与输出力矩模型。
- 本机独立标定、joint limits和HOME。
- 真实总线时序与训练command lag的对应关系。

## 5. 证据与限制

实现依据为S288 actuator、总线解析和所选task；模型参数来源见[参数说明](../../simulation/README.md)，反馈经验见[Sim2Real笔记](../07_engineering_notes/sim2real.md)。

15颗电机的个体差异、完整负载性能与制造商规格表仍需整理，不把单轴辨识等同于所有电机和所有工况。
