# 为什么选这套方案？

复刻一只机器鸭，会遇到不少选择：电机用什么、信号怎么接、主控放哪里、电池怎么固定。每个选择又会牵动机械和软件，所以这里把选型过程单独放出来。

这版围绕已有的 S288 电机、Pi Zero 2 W、成品 USB 通信板和 IMU 搭建，希望尽量减少自制电路和焊接，把主要精力放在装配、标定和运动上。尚未补齐的型号、线束和价格会保留 `TODO`，方便后续按实物补全。

## 先从最关心的部分看

- **[电机为什么用 S288](motor_selection.md)**：除了扭矩和价格，还要考虑协议、安装接口与反馈来源。
- **[Pi、通信板与 IMU](controller_selection.md)**：让现有运行代码接上硬件，并把整周期时序考虑进去。
- **[电池与供电](power_design.md)**：静止能上电和走起来不断电，中间还有不少细节。
- **[和其他方案怎么比较](design_comparison.md)**：把已知差异列清楚，缺数据的部分留空。

## 这里记录到什么程度？

代码能确认的参数会指向对应文件，称重和实验会注明来源。暂时没有同条件测试，就不比较“强多少”“便宜多少”；没有完整采购记录，也不先报一个好看的总价。

希望这些说明能帮助理解这只鸭子为什么这样做，换零件时又有哪些地方需要一起考虑。
