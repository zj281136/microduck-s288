# 方案比较与评估边界

| 指标 | XL330上游路线 | 本S288路线 | 当前证据 |
| --- | --- | --- | --- |
| 控制框架 | 上游训练/运行体系 | 延续61D/14D，S288执行器适配 | 本地源码 |
| 电机协议 | XL330对应总线 | 6Mbps S288协议 | 驱动实现 |
| 反馈语义 | 需以对应上游版本源码判断 | rotor位置+协议速度 | 解析/观测代码 |
| 机械适配 | 原版连接件 | S288专用承力/舵盘连接件 | 原鸭头完整CAD待提供 |
| 采购/成本 | 待核实当前报价 | 待补采购表 | 不做无依据评分 |
| 装配工时/难度 | 待独立复刻记录 | 待独立复刻记录 | 不填假工时 |
| 无焊接/线束 | 随实际方案核对 | 目标，尚需接口/成品线束验证 | 未完成全流程验收 |
| 动态性能/可靠性 | 待同条件实验 | 待同条件实验 | 不从模型参数推断性能排名 |

当前选择优先复用已运行的S288软件和已有硬件，代价是协议、机械、执行器及标定适配。评估应区分“源码存在”“历史单机记录”和“新手可完整复现”。
